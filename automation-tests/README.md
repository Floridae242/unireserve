# Automation tests

พื้นที่สำหรับ Robot Framework HTTP API integration tests ผ่าน RequestsLibrary ตามแผน

ยังไม่มี test suites หรือ requirements.txt เพิ่ม dependencies ที่ pin version, test fixtures, API keywords และผลลัพธ์ใน results/ เมื่อ implement

ใช้ base URLs ผ่าน environment/config และ dummy users ห้ามเก็บ tokens หรือ credentials จริงใน repository
